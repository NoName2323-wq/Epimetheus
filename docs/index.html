Inside the engine

A focused toolkit.
A layered approach.

Instead of relying on a single trick, Epimetheus combines purpose-built modules. Each one handles a different part of the Prometheus pipeline — from Luau syntax to the final reconstructed source.

Luau syntax normalizer

Desugars compound assignments and strips Luau type annotations while preserving strings, comments and nested expressions — preparing code for the Lua 5.1 parser.

engine/syntax_normalizer.py

Controlled trace emulation

A native Lua 5.1 mock sandbox captures observable behavior with execution timeouts and a restricted host environment.

lua_bin/lua5.1 · deobfuscator.py

Streaming trace filter

Removes repetitive VM allocation and unpack noise, compresses consecutive loops and keeps meaningful calls, globals, URLs and closure entries.

engine/trace_filter.py

Static constant decoder

Recovers encrypted Prometheus strings in Python, understands custom Base64/Base85 alphabets and reverses rotated constant arrays.

engine/static_decoder.py

Token-aware AST optimizer

Folds arithmetic and string expressions, propagates safe aliases and removes dead Prometheus watermark guards without rewriting literals or comments.

engine/ast_optimizer.py

Constant inlining & lexer

Unwraps ConstantArray wrappers and proxified locals. A shared lexical scanner keeps token handling consistent across the engine.

engine/constant_inliner.py · lua_lexer.py

What you get

Three files. A clearer picture.

Each processed script can produce a reconstructed source file, a constants dump and a compact execution report — ready to inspect in your editor.

MyScript.lua.deobf.lua

Reconstructed Lua source with recovered calls, functions, loops, globals and applied optimizations.

MyScript.lua.constants.lua

Extracted and decoded string and numeric constants collected from static analysis and emulation.

MyScript.lua.report.txt

Filtered trace of observed property access, method calls, global updates and detected URLs.

Get started

Ready when Linux is.

Clone the repository, make the bundled Lua runtime executable and run your first target. No external Lua compilation step is required.

Linux x86_64 (Ubuntu, Debian, Fedora, Arch, etc.)
Python 3.9 or newer
Bundled native Lua 5.1 ELF runtime
Linux only. Windows, macOS and BSD are intentionally blocked by the platform check. This is a deliberate runtime requirement, not a missing installer.
Quick installationbash · 3 steps
01 / Clone
$git clone https://github.com/NoName2323-wq/Epimetheus.git
$cd Epimetheus
02 / Permissions
$chmod +x deobfuscator.py format_lua.py lua_bin/lua5.1
03 / Run
$python3 deobfuscator.py target_script.lua
$python3 deobfuscator.py path/to/scripts --jobs 4
Run the test suite: python3 -m unittest discover tests
